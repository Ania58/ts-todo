# 📝 TypeScript Console Todo App

A simple command-line Todo application built with TypeScript to practice basic types, interfaces, and logic — without any frameworks or databases.

## 🚀 Features

- Add new todos
- Mark a task as done
- Remove tasks
- Edit task titles
- Show all current todos
- Keep a separate list of completed tasks

## 📚 What I’m Practicing

- TypeScript fundamentals (types, interfaces, inference)
- Array operations and functions
- Modularity and clean code principles
- Working in a Node.js environment with TypeScript

## 🛠 Tech Stack

- TypeScript
- Node.js

## 🧪 How to Run

Make sure you have Node.js and TypeScript installed.

## 🟢 Why This Exists
I’ve just started learning TypeScript, and I built this as a lightweight but meaningful way to apply what I’ve learned
